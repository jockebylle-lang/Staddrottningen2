# Städdrottningen 2

Ett spel för Fanny – lägg det på GitHub Pages och spara det som en app på hemskärmen.

## Lägga upp på GitHub

1. Logga in på github.com och skapa ett nytt repository (till exempel `staddrottningen2`). Välj **Public**.
2. Klicka **Add file → Upload files** och dra in **alla filer i den här mappen** (index.html, sw.js, manifest.webmanifest och de tre bilderna). Klicka **Commit changes**.
3. Gå till **Settings → Pages**. Under *Branch* väljer du **main** och **/(root)** och trycker **Save**.
4. Efter någon minut finns spelet på `https://DITTNAMN.github.io/staddrottningen2/`.

## Spara som app på iPhone

1. Öppna adressen i **Safari**.
2. Tryck på dela-knappen (fyrkanten med pilen) → **Lägg till på hemskärmen**.
3. Nu ligger Fanny med kronan på hemskärmen. **Spela alltid från den ikonen.**

## Så sparas spelet

- Spelet sparar hela tiden av sig självt på tre ställen i telefonen (en vanlig sparning, en reservkopia och en databas). Går en av dem sönder eller rensas används nästa.
- iPhone kan rensa sparningar för webbsidor i Safari som inte öppnats på ett tag. Appen på hemskärmen rensas inte på det sättet – därför ska man spela därifrån.
- Appen på hemskärmen och Safari har **olika** sparningar. Det som spelats i Safari följer inte med till appen.
- Byt aldrig adress eller namn på repositoryt efter att Fanny börjat spela – en ny adress har en ny, tom sparning.
- Under Fanny (tryck på henne uppe till vänster) finns **Sparkod**. Den kan sparas i Anteckningar som extra säkerhet, och laddas in igen med **Ladda sparkod** om något händer – även på en ny telefon.

## Uppdatera spelet

Ladda upp den nya `index.html` på samma sätt (Upload files → Commit changes). Sparningen påverkas inte. Appen hämtar den nya versionen nästa gång den öppnas med nätet på (ibland krävs att appen stängs och öppnas två gånger).
